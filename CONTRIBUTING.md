# Contributing to Visual Inspector

Thank you for your interest in contributing to `visual-inspector`!

## Code of Conduct
We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone.

## Development Workflow
1. Fork and clone the repository.
2. Set up the development environment:
   ```bash
   make setup
   ```
3. Run tests and linting before submitting a PR:
   ```bash
   make lint
   make test
   make verify
   ```
4. Follow Conventional Commits format for commit messages:
   - `feat(...)`: new feature
   - `fix(...)`: bug fix
   - `docs(...)`: documentation changes
   - `refactor(...)`: code refactoring

## Reporting Bugs
Please use the GitHub Issue Tracker and select the Bug Report template.
